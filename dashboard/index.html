Distributed Computing Concepts

  • Distributed Monitoring: Independent edge nodes collect localized sensor telemetry without single-point dependency.
  • Node Autonomy: Each node runs as a separate process/container with its own loop and interval timer.
  • Concurrent Ingestion: FastAPI server handles multiple incoming node REST payloads simultaneously.
  • Central Aggregation: SQLite + Analytics computes network-wide health and triggers threshold alerts.
